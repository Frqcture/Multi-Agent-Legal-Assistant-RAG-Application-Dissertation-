# Interview

Q: Do you have any initial thoughts about this application? Questions, concerns or anything else that comes to mind?

A: Data privacy is a concern, we handle peoples highly sensitive information. It is extremely important that this is kept secure and can be deleted from the system if necessary. On top of this, is any of the data uploaded used for training, if so this would be a massive breach of privilege. I would also like to know where data is stored, wether it is local or uploaded to a cloud service.

An answer is only as good as its source. I cannot take what this tells me at face value, so it is good that it provides me page references for all of the information that it uses.

Finally, some of the documents that we use are scanned photocopies, it would be nice if there was a way for me to be able to upload these incase i want to reference them as well.

Q: Do you have anything that you use to perform this task already?

A: Not currently, due to how underfunded we are, we can’t access software like this like larger firms. I’m used to just using Ctrl-F to find information in documents.

Q: As you don’t have access to tools like this, how do you see yourself making use of it?

A: Seeing as I have all of the evidence in front of me, it would just be useful to be able to “talk” to it. Right now, if a supervisor asks for specific information it takes me 20 mins to find it. This is how I would mainly use your application. It would massively transform the amount of clients I could help in a day.

Q: Is there any capabilities you absolutely need from a tool like this?

A: I need mass document uploads, we need to prove that our clients were in the UK for every year since they arrived, which means sometimes 50 or 60 documents need to be looked at. I also need to be absolutely sure that what it says is real, so Citations are a must, “hallucinations” absolutely cannot happen. It needs to work on slightly blurry text, it’s useless if it only works on 20% of our evidence. We need guarantees that this data is not used for LLM training or anything else. The data has to be secure at all costs.

Q: Is there anything else that you would like to have but is not necessary?

A: It would be nice to have a “Summarise like I’m 5” feature, so that it could take a complex document and sum it into a few points that I can read back to the client so that they understand. 

A way for multiple people to work on the same document set would be nice, sometimes multiple people work on the same case and we need to be able to share information between each other.

## Analysis

The main goals of this interview were twofold:

- Assess if the foundation of this idea is functional
- Determine a set of requirements for the user

### Foundation of the Idea

This is not necessarily a novel idea, but, as expected, based on this interview, alternatives are not utilised, wether this is because of cost or some other reason. Regardless, it does tell me that there is a place for this product for smaller companies and more specifically, in this example, legal clinics. As well, this lets me understand that, given certain features are available, this would be a welcome addition to the toolkit of many companies or people.

### Requirements

- Multi-document upload: Users need to be able to bulk upload documents to the application.
- Citations for ALL information used
- Robust OCR for uploaded documents
- Data Privacy and Security
